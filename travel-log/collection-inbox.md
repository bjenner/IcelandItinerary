# Iceland Trip Collection Inbox

Use this as the gathering place before editing the polished travel log. The goal is not to make it pretty on the first pass; the goal is to stop losing things.

See `media-workflow.md` for the recommended split between iCloud shared albums, YouTube videos, local raw archives, and travel-log entries.

## Curation Pass

For each day:

1. Pick one hero image.
2. Write a plain-language summary of what happened.
3. Add the real places visited with coordinates when useful.
4. Add the campground or overnight context.
5. Add weather and road notes that explain decisions.
6. Add 3-12 selected media items, with external links for large videos.
7. Add source links so the raw material can be found later.

## Media Storage Pattern

Keep large originals outside Git. Good homes:

- Local archival folders on an external drive or Photos library
- iCloud or Google Photos albums for shared family browsing
- YouTube/Vimeo for edited videos
- Object storage such as Cloudflare R2 for web-ready media files

Put only small web-ready assets, poster frames, and metadata in this repo.
